# Duhaa Feedback Triage

Last updated: 2026-06-25

## Inbox Boundary

- Use only the connected Duhaa feedback Gmail account: `duhaaapp@gmail.com`.
- Search narrowly with queries like:
  - `-in:spam -in:trash newer_than:730d "Duhaa Feedback"`
  - `-in:spam -in:trash newer_than:730d "Duhaa Bug Report"`
  - `-in:spam -in:trash newer_than:730d (TestFlight OR bug OR feedback OR prayer OR Quran OR widget OR onboarding)`
- Do not inspect a personal mailbox for Duhaa work. If feedback is forwarded from elsewhere, ask the sender to forward it into `duhaaapp@gmail.com` or paste/export only the relevant message.

## Gmail Auto-Routing

- Gmail labels are the "tabs" for this inbox: `Feedback`, `Feedback/Quran`, `Feedback/Duas`, `Feedback/Bugs`, `Feedback/Ideas`, `Feedback/Prayer Times`, `Feedback/Widgets`, `Feedback/General`, `Feedback/Implemented`, and `Feedback/Needs Review`.
- Import `docs/gmail-feedback-filters.xml` in Gmail: Settings -> See all settings -> Filters and Blocked Addresses -> Import filters.
- After importing, new app feedback routes by the structured subject tags generated by Duhaa, such as `[quran]`, `[duas]`, `[bug]`, `[widgets]`, `[prayer-times]`, `[idea]`, and `[general]`.
- The Gmail connector can label existing messages, but it cannot create persistent future filters directly; keep the XML file as the source of truth for those Gmail rules.
- Du'a content requests are auto-labeled `Feedback/Duas` and `Feedback/Needs Review` because religious content should not ship without source review.

## Triage Rules

- Classify every item by area: prayer-times, notifications, onboarding, quran, widgets, duas, learn, membership, design, performance, privacy, or other.
- Severity:
  - P0: app-breaking, privacy/security risk, wrong prayer-time behavior, or content that could mislead worship.
  - P1: major launch blocker or repeated user pain.
  - P2: important polish, confusing flow, missing expected option.
  - P3: nice-to-have, content expansion, or future feature.
- Product fixes can move directly to implementation with a focused test.
- Religious content, high-latitude prayer-time policy, monetization, Quran licensing, and medical/legal-style advice must be marked `Needs review` before code/content changes ship.
- Group duplicates before implementation. Fix the behavior once, then note all related Gmail message IDs.

## Fix Loop

1. Search the feedback inbox using the narrow queries above.
2. Read relevant messages only, summarize them, and classify severity.
3. Add or update a row in this file.
4. For implementable product feedback, write or update targeted tests first when there is business logic.
5. Implement the smallest complete fix that matches Duhaa's mission: hope, calm, privacy, no guilt.
6. Run the relevant tests and record any manual QA needed on a real iPhone.
7. Label the Gmail message as implemented, needs-review, duplicate, or backlog.
